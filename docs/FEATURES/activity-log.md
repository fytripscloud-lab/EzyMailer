# Feature: Activity Log

## Goal

Track user and automation actions inside the dashboard.

## Behavior

- Show recent events in reverse chronological order
- Record launch, stop, reset, login, logout, and content actions
- Keep the panel visible in the sidebar
- Mirror send-log styling in the blaster tab
- Pair with toast notifications for quick action feedback

## Notes

- The log is currently local and design-focused
- Persistence will be added later with project memory and app storage
