# Feature: Dashboard Shell

## Goal

Provide the main application shell shown after login with a modern dark layout.

## Layout

- Top navigation bar with brand, status, and user badge
- Frameless custom window chrome with a custom close icon
- Left logo area
- Left sidebar control panel
- Main tabbed workspace
- Activity log
- Start Browser and Start Campaign actions
- Toast notifications for user actions
- Confirmation prompt before launch

## Sidebar controls

- Number of windows
- Start Browser button
- Pause button
- Reset button
- Browser mode: Incognito or Normal
- Active sessions list
- Activity log
- Browser state and activity events persist through the backend API into the dedicated AWS MySQL database
