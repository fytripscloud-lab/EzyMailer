# Feature: Settings

## Goal

Expose sending and runtime settings in a structured design.

## Sections

- Sending settings
- Proxy settings
- Additional startup tabs

## Controls

- Per-sender limit
- Delay between emails
- Delay type
- Retry failed sends
- Email send order
- Window send mode
- Enable proxy
- Startup URL

## Notes

- All controls are currently placeholders
- They define the final configuration surface for later implementation
