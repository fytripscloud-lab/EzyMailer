# Feature: Subject + Body Editor

## Goal

Provide a modern message composition surface for the selected window.

## Layout

- Window indicator pill
- Subject input
- Body mode toggles
- Normal message editor
- HTML message code editor
- Footer actions for load, clear, preview, and guide
- Preview opens a separate dark HTML window, using rendered HTML when HTML mode is selected
- Design-time spintax subject sample
- Convert to File modal for output options

## Notes

- The editor is currently a design-first placeholder
- Switching to HTML Message swaps the message view to a code-friendly editor
- The convert workflow opens a modal with output format references
- Content logic will be connected during the business-logic phase
