# EzyMailer

Windows desktop email automation app in Python.

## Current milestone

- Login page with default credentials
- Modern dashboard shell with sidebar, top bar, activity log, and tabbed workspace
- Complete design pass for Data, Subject+Body, Content, Settings, Blaster, and Tags
- Project memory and update records in markdown
